# 과제 제출

과제를 매번 같은 규칙으로 모음 레포에 올리고 링크까지 건넨다.
사용자는 코딩 초보다. 영어 용어는 한글 발음을 괄호로 붙인다. 예: push(푸시).

## 고정 값 (묻지 않는다)

- 레포: `https://github.com/castlegyun/aiffel-agent-3` (브랜치 `main`)
- 로컬 위치: `C:\Users\lsg95\Downloads\aiffel-agent-3` (현재 작업 폴더가 이 레포 안이면 그대로 사용)
- 폴더 규칙: 레포 루트에 `NN-영어소문자-하이픈` (예: `05-chatbot`). 상위 폴더 없음.
- Pages 주소: `https://castlegyun.github.io/aiffel-agent-3/<폴더이름>/`

## 절차

1. **대상 확인**: 올릴 과제 폴더를 확인한다. 현재 폴더가 과제면 후보로 제시한다.
2. **레포 최신화**: `git status`로 저장 안 된 변경이 있으면 멈추고 알린다. 깨끗하면 `git pull`.
3. **이름 제안**:
   - 올릴 폴더가 이미 레포 루트 안에 있고 `NN-`처럼 번호를 갖고 있으면(이름이 비어 있는 `05-`도 포함) 그 번호를 그대로 쓴다. 번호를 새로 매기지 않는다. 번호 뒤 이름이 비어 있으면 과제 내용을 보고 영어 이름을 제안해 폴더 이름을 바꾼다.
   - 번호가 없거나 레포 밖의 폴더면 루트의 `NN-` 폴더 중 가장 큰 번호 + 1을 쓰고, 과제 내용을 보고 영어 이름을 제안한다.
   - 이름은 영어 소문자, 공백은 하이픈으로.
4. **복사**: 레포 밖의 폴더면 `NN-이름/`으로 복사하되 아래는 뺀다. 이미 레포 안에 있으면 복사 없이 아래 항목만 점검한다.
   - `.git` 폴더 (레포 안에 레포가 생겨 GitHub에서 폴더가 안 열린다)
   - `node_modules`, `.venv`, `__pycache__` 등 설치·임시 폴더
   - `.env`, API 키가 든 파일 (`.env.example`은 허용). 발견하면 빼고 알린다.
5. **과제 README**: 폴더 안에 README가 없으면 과제명 + 한 줄 설명만 담아 만든다.
6. **루트 README 표 갱신**: `## 과제 목록` 표에 한 줄 추가한다. 기존 열 형식을 그대로 따른다.
   `| NN | [이름](NN-이름) | 설명 | 기술 | 바로가기 |`
   - `index.html`이 있는 웹 과제: 바로가기에 `[▶ 게임 하기](Pages 주소)` 형태
   - 외부 배포(Render 등)가 있으면 `[배포](주소)`
   - 그 외: `[README](NN-이름/README.md)`
7. **push 전 확인 (한 번만)**: 폴더 이름, 추가될 파일 목록(`git status`), README 변경을 한 번에 보여주고 올려도 되는지 묻는다.
8. **commit(커밋) & push(푸시)**:
   ```
   git add .
   git commit -m "NN-이름 과제 추가"
   git push
   ```
   push가 거절되면 `git pull` 후 재시도하고, 충돌이 나면 멈추고 설명한다.
9. **링크 만들기**: 아래 "제출 링크" 참고.

## 제출 링크

- 소스 링크 (항상): `https://github.com/castlegyun/aiffel-agent-3/tree/main/NN-이름`
- 실행 링크 (`index.html`이 있는 웹 과제만): Pages 주소. 처음 올린 직후엔 반영에 1~2분 걸릴 수 있다고 알린다.
