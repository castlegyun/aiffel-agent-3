# 듣기용 대본 변환 규칙

교안 구간(`segments.json`의 `raw`)을 음성 엔진이 그대로 읽어도 알아들을 수 있는 글(`listen`)로 바꾸는 규칙이다.
변환은 AI(Claude Code)가 이 규칙만 보고 한다. 정답 목록(`answer_key.json`)은 보지 않는다.
규칙의 예시는 시험 구간에 없는 낱말로만 들었다(정답을 규칙에 미리 넣지 않으려고).

## 1. 내용은 그대로 둔다
- 문장의 뜻과 순서를 바꾸지 않는다. 새 설명을 덧붙이지 않는다. 문장을 빼지 않는다.
- 바꾸는 것은 **소리로 읽기 어려운 글자**뿐이다: 영어, 숫자, 기호, 마크다운 표시.

## 2. 읽지 않는 구간
| 구간 | 처리 |
|---|---|
| 표 (`kind: table`) | 읽지 않는다. `listen`은 빈 글, `skip`은 `"table"` |
| 그림 (`kind: image`, `<figure>`, `![...]`) | 읽지 않는다. `skip`은 `"image"` |
| 글 안에 섞인 그림 줄 | 그 줄만 지우고 나머지 글은 읽는다 |
| 출처 목록 (논문·문서 제목과 링크만 나열된 구간) | 읽지 않는다. `skip`은 `"reference"` |

## 3. 영어
- 소리 나는 대로 한글로 쓴다. 널리 쓰이는 한국어 표기를 따른다.
  - 낱말: YOLO → 욜로, embedding → 임베딩, Hugging Face → 허깅 페이스, ResNet → 레즈넷
  - 글자를 하나씩 읽는 약어: GPU → 지피유, API → 에이피아이, URL → 유알엘
- 괄호 속 풀이 영어는 쉼표로 이어 읽는다: `RAG(Retrieval-Augmented Generation)` → `래그, 리트리벌 오그멘티드 제너레이션`
- 모델·파일 이름처럼 기호가 섞인 이름은 기호를 빼고 조각마다 소리 나는 대로 이어 쓴다. 조각은 빼지 않는다.
  - `/`, `-`, `_` → 띄어쓰기. `.`(파일 확장자 앞) → `점`
  - 이름 속 숫자는 한자어로 읽는다: `yolo11n-seg.pt` → `욜로 일일 엔 세그 점 피티`

## 4. 숫자와 기호
- 단위가 붙은 정수(10건, 40장, 5위)는 그대로 둔다.
- 소수는 한 자리씩 읽는다. 끝의 0도 읽는다: `0.25` → `영 점 이오`, `0.70` → `영 점 칠영`, `3.0` → `삼 점 영`
- 이름 뒤 버전 숫자는 영어식으로 읽는다: `Llama 3` → `라마 쓰리`, `Python 3.11` → `파이썬 쓰리 점 일일`
- `%` → `퍼센트`, `~`(범위) → `에서 … 까지`, 따옴표는 그대로 둔다.

## 5. 마크다운과 목록
- `**`, `#`, `>`, `` ` `` 같은 표시는 지운다. 제목은 문장처럼 끝에 마침표를 붙인다.
- 번호 목록 `1.` → `첫째,`, `2.` → `둘째,` … 점 목록 `-`는 지우고 문장마다 마침표로 끝낸다.
- 코드 블록 안이 한국어 지시문이면 줄마다 한 문장으로 읽는다. 코드 울타리(```` ```text ````)는 읽지 않는다.

## 출력 형식
```json
[{"id": "s008", "listen": "오늘 하는 일은 …", "skip": null}]
```
