for문: 1부터 5까지 더하기

이 코드는 1+2+3+4+5를 계산해서 15를 출력한다.

새 용어

  • for문 = 정해진 횟수나 목록만큼 같은 동작을 반복하는 문장
  • 변수 = 값에 이름을 붙여 저장해 두는 곳
줄코드전체에서 하는 역할
1total = 0합계를 담을 변수를 0으로 시작한다
2for n in range(1, 6):1~5를 차례로 n에 넣으며 아래 줄을 반복한다
3    total = total + n지금까지의 합계에 n을 더해 합계를 갱신한다
4print(total)반복이 끝난 뒤 최종 합계를 출력한다
줄코드실제로 일어나는 일
1total = 0total이라는 이름을 만들고 숫자 0을 저장한다. 이 시점의 total은 0이다.
2for n in range(1, 6):range(1, 6)이 1, 2, 3, 4, 5를 차례로 만든다. 매 반복마다 n에 그 숫자가 들어가고, 들여쓴 줄을 한 번 실행한다. 모두 5번 반복한다. 끝 숫자 6은 포함되지 않는다.
3    total = total + n오른쪽 total + n을 먼저 계산하고, 그 결과를 다시 total에 저장한다. 반복마다 total은 0 → 1 → 3 → 6 → 10 → 15로 바뀐다.
4print(total)들여쓰지 않았으므로 반복 밖의 줄이다. 반복이 모두 끝난 뒤 한 번만 실행되어 total의 값 15를 화면에 보여 준다.
  • total(토털): 합계. 이 코드에서 합계를 담는 변수 이름
  • for(포): ~마다. 반복문을 시작하는 단어
  • in(인): ~ 안에서. 목록 안의 값을 하나씩 꺼낼 때 쓰는 단어
  • range(레인지): 범위. range(1, 6)은 1부터 5까지 숫자를 차례로 만들어 주는 명령이다. 끝 숫자 6은 포함되지 않는다
  • print(프린트): 출력하다. 값을 화면에 보여 주는 명령

그림 종류: 단계별 실행 과정

고른 이유: 반복할 때마다 total과 n의 값이 한 줄씩 바뀌는 코드라서, 글보다 한 단계씩 따라가며 보는 그림이 이해에 도움이 된다.
