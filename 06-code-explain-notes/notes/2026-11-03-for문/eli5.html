for문, 아주 쉽게

1부터 5까지 더하면 15가 된다.

total = 0
for n in range(1, 6):
total = total + n
print(total)

1. 시작: total은 0

total0

2. n이 1, 2, 3, 4, 5로 바뀌면서 같은 줄이 5번 실행된다

1번째 · n=10+1=1
2번째 · n=21+2=3
3번째 · n=33+3=6
4번째 · n=46+4=10
5번째 · n=510+5=15

3. 끝: print가 total을 보여 준다

15
for(포) ~마다 range(레인지) 범위. 1~5 (6은 빠짐) total(토털) 합계 print(프린트) 화면에 보여 주기
