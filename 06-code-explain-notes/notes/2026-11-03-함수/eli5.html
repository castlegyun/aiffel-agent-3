함수, 아주 쉽게

코드 덩어리에 이름을 붙여 두고, 이름을 부르면 실행한다.

def add(a, b):
return a + b
result = add(2, 3)

1. 이름 붙이기

defadd코드 묶음에 add라는 이름이 붙는다. 아직 실행되지 않는다.

2. 부르기 (호출)

add(2, 3)add를 부르면 묶음이 실행된다.

3. 값이 들어간다 (매개변수)

a2b3

4. 계산한다

2+3=5

5. 결과가 나온다 (반환값)

result5return 뒤의 5가 부른 자리로 돌아온다.
function(펑션) 함수 call(콜) 부르다, 호출 parameter(퍼래미터) 매개변수 return(리턴) 돌려주다 def(데프) 함수를 만들 때 쓰는 단어 (파이썬)
