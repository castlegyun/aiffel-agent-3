함수(function)

함수는 반복해서 쓰는 코드에 이름을 붙여 묶어 둔 것이고, 그 이름으로 불러서 실행한다.

새 용어

  • 함수 = 이름을 붙여 묶어 둔 코드 덩어리
  • 호출 = 함수 이름을 써서 그 함수의 코드를 실행시키는 일
  • 매개변수 = 함수가 받는 입력값을 담는 변수
  • 반환값 = 함수가 끝나면서 호출한 자리로 돌려주는 결과
  • 함수 = 이름을 붙여 묶어 둔 코드 덩어리다.
  • 함수 이름을 써서 호출하면 묶어 둔 코드가 실행된다.
  • 입력은 매개변수로 받고, 결과는 반환값으로 돌려준다.
  • 파이썬에서는 def 로 함수를 만든다.
#원문쉽게 풀어쓰기
1함수는 반복해서 쓰는 코드를 하나의 이름으로 묶은 것이다.같은 코드를 여러 번 써야 할 때, 그 코드에 이름 하나를 붙여 한 덩어리로 저장해 둔 것이 함수다. 같은 코드를 다시 쓰지 않고 이름만 쓰면 된다.
2함수를 호출하면 묶어 둔 코드가 실행된다.호출 = 함수 이름을 써서 실행하라고 시키는 일이다. greet() 처럼 이름 뒤에 괄호를 쓰면, 그 이름에 묶인 코드가 위에서부터 차례로 한 번 실행된다.
3매개변수는 함수가 받는 입력값이고, 반환값은 함수가 돌려주는 결과다.매개변수는 함수를 부를 때 괄호 안에 넣어 준 값을 받는 변수다. 반환값은 함수가 끝나면서 return 뒤의 값을 호출한 자리로 돌려주는 것이다.
4def 키워드로 정의한다.def 는 "이 이름으로 함수를 만든다"고 파이썬에 알리는 단어다(파이썬 기준). def greet(): 처럼 쓰고, 아랫줄을 들여써서 함수 안의 코드를 적는다.
  • function(펑션): 함수, 기능
  • call(콜): 부르다. 호출의 영어
  • parameter(퍼래미터): 매개변수의 영어
  • return(리턴): 돌려주다. 반환값을 돌려줄 때 쓰는 단어
  • def(데프): define(디파인, 정의하다)의 줄임말. 파이썬에서 함수를 만들 때 쓰는 단어
  • keyword(키워드): 파이썬이 정해 둔 특별한 단어

그림 종류: 데이터 이동 구조도

고른 이유: 값이 함수 안으로 들어가고(매개변수) 결과가 나오는(반환값) 이동이 핵심이라서, 입력 → 함수 → 출력을 잇는 그림이 글보다 빠르다.
