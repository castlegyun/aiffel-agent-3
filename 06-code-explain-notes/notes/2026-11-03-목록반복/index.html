for문으로 목록 하나씩 꺼내기

이 코드는 목록 안의 값을 하나씩 꺼내 화면에 한 줄씩 출력한다.

새 용어

  • 목록 = 여러 값을 순서대로 담아 두는 묶음. 대괄호로 만든다
  • for문 = 목록이나 범위의 값을 하나씩 꺼내며 같은 동작을 반복하는 문장
  • 변수 = 값에 이름을 붙여 저장해 두는 곳
  • 문자열 = 따옴표로 감싼 글자 값
줄코드전체에서 하는 역할
1fruits = ["apple", "pear", "tangerine"]과일 이름 세 개를 담은 목록을 fruits에 저장한다
2for fruit in fruits:목록의 값을 하나씩 fruit에 넣으며 아래 줄을 반복한다
3    print(fruit)꺼낸 값을 화면에 출력한다
줄코드실제로 일어나는 일
1fruits = ["apple", "pear", "tangerine"]대괄호 안에 문자열 세 개를 쉼표로 나열해 목록을 만들고, fruits라는 이름에 저장한다. 순서는 apple, pear, tangerine이다.
2for fruit in fruits:fruits 안의 값을 맨 앞부터 하나씩 꺼내 fruit에 넣고, 들여쓴 줄을 한 번 실행한다. 값이 3개라서 3번 반복한다. fruit은 처음에 apple, 다음에 pear, 마지막에 tangerine이다.
3    print(fruit)들여쓴 줄이라 반복할 때마다 실행된다. 화면에 apple, pear, tangerine이 한 줄씩 출력된다.
  • fruits(프룻츠): 과일들. 이 코드에서 목록을 담는 변수 이름
  • fruit(프룻): 과일 하나. 이 코드에서 반복마다 값이 들어가는 변수 이름
  • for(포): ~마다. 반복문을 시작하는 단어
  • in(인): ~ 안에서. 목록 안의 값을 하나씩 꺼낼 때 쓰는 단어
  • print(프린트): 출력하다. 값을 화면에 보여 주는 명령
  • apple(애플): 사과
  • pear(페어): 배
  • tangerine(탠저린): 귤

그림 종류: 단계별 실행 과정

고른 이유: 반복할 때마다 fruit에 들어가는 값이 바뀌고 한 줄씩 출력되는 코드라서, 한 단계씩 따라가는 그림이 이해에 도움이 된다.
