2해법: 우리가 잡음을 섞어요

학습

깨끗한 그림에 우리가 고른 무작위 숫자(잡음)를 더해요. 단계가 갈수록 잡음이 많아져요. 우리가 섞었으니까 섞인 잡음이 무엇인지 우리가 알아요. 이제 정답이 있는 문제가 됐어요.

위 그림은 아래 슬라이더와 같은 계산으로 이 페이지에서 직접 만든 것이에요.

3신경망은 “섞인 잡음”을 맞혀요

학습
잡음 섞인 그림
+ 몇 단계인지
신경망
섞인 잡음을 예측
예측 − 정답 잡음
차이를 제곱 → 작아지게 고침

정답 잡음은 우리가 갖고 있어서, 채점하는 신경망이 따로 필요 없어요.

4단계가 갈수록 원본은 줄고 잡음은 늘어요

원본 비율
1.00
잡음 비율
0.00

계산: 섞인 그림 = 원본 × √ᾱ + 잡음 × √(1−ᾱ). ᾱ(알파 바)는 t가 커질수록 1에서 0으로 줄어요. 두 비율을 그냥 더하면 1이 아니에요. 제곱해서 더해야 1이에요. 1000단계와 ᾱ 곡선은 설명용 예시예요. 실제 값은 모델마다 달라요.

5그림 만들기는 거꾸로 해요

생성

순수한 잡음에서 시작해요. 신경망이 “여기 섞인 잡음”을 예측하면, 그만큼 조금 빼요. 이것을 정해진 횟수만큼 반복해요. 반복 횟수가 step(스텝) 수예요.

이 그림은 원본을 알고 거꾸로 보여 준 것이에요. 실제 생성에서는 원본이 없고, 신경망의 예측으로만 잡음을 빼요.

학습할 때 나눈 단계 수(여기서는 1000)와 생성 스텝 수는 달라도 돼요. 스텝이 4번이면 단계를 크게 건너뛰며 내려와요. (원문에 없는 설명이에요.)

2021년 CLIP(클립)은 그림과 문장을 같은 좌표 공간에 놓았어요. 2022년에는 글만 학습한 언어모델이 문장을 더 잘 읽는다는 결과가 나왔어요.

7빨라졌어요: 50번 → 4번

예전 기본값은 50스텝이었어요. 증류는 선생 모델이 50스텝 걸려 낸 결과를, 새 모델(학생 모델)이 몇 스텝 만에 내도록 학습시키는 방법이에요.

2022년 무렵: 50스텝
증류한 모델: 4스텝 (원문: 4~9스텝)

모델마다 guidance(가이던스) 권장값이 달라요. 모델 설명서(모델 카드)를 확인해요.
