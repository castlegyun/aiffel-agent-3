탐지 모델 재기, 아주 쉽게

박스를 몇 개 그렸나가 아니라 무엇을 헛짚었고 무엇을 놓쳤나를 센다.

용어 먼저

  • 임계값 = 결과로 남길 박스의 최소 점수. 이보다 낮은 박스는 버려요
  • TP(티피), 맞힘 = 박스를 냈고, 실제로 대상이 맞음
  • FP(에프피), 오탐 = 박스를 냈는데, 대상이 아님
  • FN(에프엔), 미탐 = 실제 대상인데, 박스가 없음
  • 정밀도 = 낸 박스 중에 맞은 비율
  • 재현율 = 실제 대상 중에 맞힌 비율
  • IoU(아이오유) = 모델 박스와 정답 박스가 얼마나 겹치는지 나타낸 0~1 값
  • AP(에이피), mAP(엠에이피) = 임계값 하나가 아니라 여러 임계값의 결과를 모아 낸 점수

결론부터

모델은 박스 개수가 아니라 맞힌 것과 놓친 것으로 재요. 그리고 어떤 오류가 더 위험한지는 하는 일마다 달라요.

1임계값을 움직이면 오탐과 미탐이 서로 바뀌어요

원문 사진: 안전모 10개, 배경 조명 2개. 모델이 박스 10개를 그렸다.

아래 막대의 점수는 이해를 돕기 위해 제가 정한 값이에요. 임계값 0.40과 0.60에서 원문과 같은 숫자가 나오게 맞췄어요. 막대를 움직여 보세요.

임계값0.40
맞힘 TP오탐 FP미탐 FN걸러진 조명

2정밀도와 재현율은 나누는 수가 달라요

정밀도: 모델이 낸 박스 10개 중 맞힌 것 8 ÷ 10 = 0.8
재현율: 실제 안전모 10개 중 맞힌 것 8 ÷ 10 = 0.8

정밀도는 오탐이 늘면, 재현율은 미탐이 늘면 떨어진다.

파랑 = 맞힘, 주황 = 오탐, 점선 = 미탐. 둘 다 0.8인 것은 오탐과 미탐이 2개씩이라서다.

3IoU: 박스가 맞았다는 기준

클래스가 맞아도 박스 위치가 많이 어긋나면 맞은 걸로 치지 않아요.

정답 박스 100, 모델 박스 100, 겹친 곳 60 (설명용 숫자)
합친 넓이 = 100 + 100 − 60 = 140
IoU = 60 ÷ 140 ≈ 0.43 → 기준이 0.5면 맞힘이 아니에요

같은 정답에 박스 여러 개가 몰리면 하나만 맞힘, 나머지는 오탐이에요. mAP@0.5의 0.5는 이 겹침 기준이고, 위의 박스 점수 임계값과 다른 숫자예요. 여기 넓이는 박스의 넓이(픽셀)이고, 아래 AP는 그래프의 넓이예요.

4AP와 mAP: 임계값 하나에 묶이지 않는 점수

  • 임계값을 바꿔 가며 정밀도와 재현율을 구해요. 위 막대를 움직일 때마다 점 하나가 나와요.
  • 점들을 이은 곡선 아래 넓이가 AP예요. 클래스 하나의 점수예요.
  • 클래스별 AP를 평균한 게 mAP예요.

두 점은 위 원문 예시 값이에요. 곡선 모양은 설명용으로 그렸고, 실제로는 평가 자료 전체에서 임계값마다 점을 구해요.

원문 예시: 안전모 AP 0.8, 조끼 AP 0.6 → mAP = (0.8 + 0.6) ÷ 2 = 0.7

5비교표를 읽을 때

  • mAP@0.5: IoU가 0.5 이상이면 맞힘으로 쳐서 계산한 점수예요.
  • mAP@0.5:0.95: 겹침 기준을 0.50, 0.55, …, 0.95 열 단계로 바꿔 각각 계산해 평균한 점수예요. 박스 위치를 더 엄격하게 채점해요.
  • 같은 평가 자료, 같은 열끼리만 비교해요. 어느 열을 보느냐에 따라 모델 순위가 바뀔 수 있어요.

표에서 후보를 고른 뒤에는, 실제 업무 사진에서 쓸 임계값 하나를 정해 오탐과 미탐을 직접 세요.
