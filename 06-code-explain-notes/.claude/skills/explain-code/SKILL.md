# 코드 해설 노트 만들기

코드를 초보자용 노트로 바꿔 `06-code-explain-notes/notes/<날짜-주제>/index.html` 에 저장한다.
사용자는 코딩 초보다. 영어 용어는 한글 발음을 괄호로 붙인다. 예: import(임포트).

설명 규칙은 `06-code-explain-notes/CLAUDE.md` 8개를 따른다. 작업 전에 읽는다.

## 입력 (두 방식)

- 파일 경로: `/explain-code game.js` → 그 파일을 읽는다. 파일이 없으면 만들지 말고 경로를 다시 묻는다.
- 붙여 넣은 코드: 채팅에 있는 코드를 그대로 쓴다.
- 둘 다 없으면 무엇을 해설할지 묻는다. 언어가 불분명하면 묻는다.

## 절차

1. **코드 읽기**: 코드 전체와 언어를 확인한다. 코드가 길면(60줄 넘으면) 해설할 범위를 사용자에게 묻는다.
2. **주제와 폴더 이름**: 주제는 짧은 한글 낱말 1~3개(예: `for문`). 폴더는 `06-code-explain-notes/notes/YYYY-MM-DD-주제/`. 같은 이름이 있으면 `-2`를 붙인다.
3. **내용 작성** (규칙 1~8 적용):
   - 제목, 결론 한 줄(이 코드가 무엇을 하는지)
   - 새 용어: `용어 = 한 줄 정의`. 비유 없이 실제 동작으로 쓴다.
   - 흐름 버전: 줄마다 한 줄 이내, 전체에서 하는 역할
   - 자세히 버전: 줄마다 명령어가 실제로 어떻게 작동하는지, 값이 어떻게 바뀌는지. 설치 방법은 뺀다.
   - 단어장: `단어(한글 발음): 뜻`
   - 추측은 "추측:"으로 표시한다. 모르면 모른다고 쓴다.
4. **HTML 만들기**: `06-code-explain-notes/templates/note.html` 을 복사해 `{{...}}` 자리를 채운다. 틀의 CSS와 JS는 바꾸지 않는다.

   | 자리 | 채울 것 |
   |---|---|
   | `{{TITLE}}` | 제목 |
   | `{{SUMMARY}}` | 결론 한 줄 |
   | `{{TERMS}}` | `<li><strong>용어</strong> = 정의</li>` 여러 줄 |
   | `{{FLOW_ROWS}}`, `{{DETAIL_ROWS}}` | `<tr><td class="n">1</td><td><code>코드</code></td><td>설명</td></tr>` 코드 줄마다 한 행 |
   | `{{WORDS}}` | `<li><strong>단어</strong>(발음): 뜻</li>` 여러 줄 |

   코드 안의 `<`, `>`, `&` 는 `&lt;`, `&gt;`, `&amp;` 로 바꾼다. 들여쓰기는 `&nbsp;` 로 유지한다.
5. **보관함 목록 갱신**: `06-code-explain-notes/notes/index.json` 을 읽어(없으면 `[]`) 맨 앞에 추가한다.
   `{"id": "폴더이름", "title": "제목", "summary": "결론 한 줄", "date": "YYYY-MM-DD"}`
6. **확인**: 만든 파일에 `{{` 가 남아 있지 않은지, `index.json` 이 올바른 JSON인지 확인한다.
7. **알리기**: 만든 파일 경로 하나와 결론 한 줄만 알린다. 커밋과 푸시는 사용자가 요청할 때만 한다.
