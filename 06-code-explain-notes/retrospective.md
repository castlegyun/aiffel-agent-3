# 회고록: 코드 해설 노트

> **초안.** 작업 기록(커밋, 대화)을 바탕으로 Claude Code가 썼다. 제출 전에 본인의 생각과 느낌으로 고치고 보탤 것.

## 만든 것

코드나 배운 글을 넣으면 쉬운 해설 노트(주석·풀어쓰기·단어장·그림)로 바꿔 주는 스킬 `/explain-code`와, 노트를 모아 보는 정적 웹사이트(Render, https://aiffel-agent-3.onrender.com/). 노트 5개를 만들었다: for문, 함수, 스펙 주도 개발, 굴러가는 첫 조각, 목록 반복.

## 내린 결정과 이유

| 결정 | 이유 |
|---|---|
| 해설 생성은 Claude Code, 웹사이트는 보기 전용 | API 키가 필요 없고, 키 노출과 비용이 없다 (PRD 1장) |
| 종류(코드/텍스트)를 직접 고르게 함 | 자동 판단은 코드가 섞인 글에서 헷갈릴 수 있다. 사용자가 직접 고르는 쪽을 택했다 |
| 새 용어는 한글 개념어만, 영어는 단어장에 | 두 곳에 같은 낱말이 설명되어 겹쳤다. 역할을 갈라 중복을 없앴다 |
| 시뮬레이터는 틀 한 번 + 단계 데이터(JSON)만 채움 | 매번 통째로 만들면 품질이 들쭉날쭉하고 오래 걸린다. 틀을 쓰니 for문과 목록 반복 두 노트가 같은 모양으로 나왔다 |
| 배포는 GitHub Pages 대신 Render | 지시를 받았다(GitHub Pages 금지). 정적 사이트라 Render 정적 사이트로 옮긴다 |
| 종합 정리는 Cards 테마, 테마 선택칸은 남김 | 처음에 도구 막대 전체를 숨겨 테마 선택칸까지 없앴다. 사용자가 3개 테마 중 2번째를 좋아했다는 말로 알아챘고, 피드백 버튼만 숨기도록 고쳤다 |
| diagram-design 스타일은 질문 없이 기본값 | 단순한 기본 스타일로 정하고, 이후 모든 구조도에 같은 스타일을 썼다 |

## 잘못한 것과 배운 것

- **도구 막대를 통째로 숨긴 실수:** 거슬리는 것(Reply·Remark 버튼)만 없애려다 쓸모 있는 것(테마 선택)까지 없앴다. 화면을 눈으로 확인하고 사용자에게 보여 주면서 발견했다. 숨길 대상을 정확히 좁히는 것이 중요했다.
- **원문에 없는 설명 표시:** 텍스트 노트에서 원문이 정의하지 않은 말(목업 데이터, HTML 등)은 "원문 밖 일반 설명"으로, 확인하지 못한 출처(Softvery Solutions, 리드 호프먼)는 "확인하지 않음"으로 노트에 적었다. 모르는 것을 아는 것처럼 쓰지 않으려 했다.
- **검증:** 코드 노트는 시뮬레이터 마지막 값이 실제로 실행한 결과와 같은지 확인했다(15, 그리고 apple/pear/tangerine).

- **GitHub Pages 지시를 늦게 알았다:** 이 레포는 앞선 과제(02, 03) 때문에 GitHub Pages가 이미 켜져 있어서, 푸시만으로 06 폴더도 github.io 주소에 공개되었다. 기획서(PRD)에 GitHub Pages를 적은 것도, 푸시 후 그 주소를 확인한 것도 지시와 어긋났다. 배포 방식은 시작할 때 확인해야 했다.

## 미룬 것

| 미룬 기능 | 이유 |
|---|---|
| 보관함 검색, 모든 노트 단어장을 한곳에 모으기, `/feynman-technique` 모드 | PRD의 2단계. MVP를 먼저 굴리는 것이 우선이었다 |
| 밝은 모드, 모바일 폭 확인 | 작업 중 어두운 모드 화면으로만 확인했다 |
| "그림 필요 없음" 분기 시험 | 시험할 단순 개념(한두 줄) 샘플을 아직 넣지 않았다 |
| diagram-design 연결선 규칙 검사 | 설치본에 검사 스크립트(`verify-geometry.py`)가 없어 자체 검사(`self_check.py`)와 눈으로만 확인했다 |

## 확인이 필요한 것

- 웹사이트가 보기 전용이라 "실행 가능한 웹 서비스"로 인정되는지 강사에게 확인 (PRD 13장).

## AI 활용

- Claude Code 대화 전체(기획 질문, 설계 결정, 구현, 화면 확인)를 지우지 않고 남겼다.
- 직접 만든 스킬 `explain-code`를 실제로 두 번 호출해 시험했다: 텍스트 붙여 넣기 방식, 코드 파일 경로 방식.
- 다른 스킬을 조합했다: answer-me-with-html(종합 정리), diagram-design(구조도), eli5(아주 쉽게).
- Claude가 만든 결과를 그대로 믿지 않고, 브라우저에서 직접 열어 보고 계산값을 맞춰 보았다.
