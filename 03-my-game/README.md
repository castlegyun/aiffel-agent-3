# 심연의 생존자

HTML · CSS · JavaScript만으로 만든 다크 판타지 **뱀서라이크** 게임입니다. 4분 동안 살아남거나, 그 전에 보스를 쓰러뜨리면 승리합니다.

**▶ 바로 플레이: https://castlegyun.github.io/aiffel-agent-3/03-my-game/**

이미지·오디오 파일이 없습니다. 캐릭터는 코드 속 도트 도안으로, 효과음은 Web Audio로 직접 만들었습니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| (자동) | 가장 가까운 적을 조준해 공격 |
| ESC | 일시정지 |
| M | 소리 켜기/끄기 |
| 터치 | 화면을 누르고 드래그하면 조이스틱, 오른쪽 위 ❚❚ 버튼으로 일시정지 |

## 주요 기능

- **무기 4종**: 불꽃탄(다발 발사 + 폭발), 회전 구슬(혜성 꼬리), 레이저(광선 + 관통), 연쇄 번개(맞은 적에서 주변 적으로 확산). 레벨 5가 되면 진화합니다.
- **스킬 Lv3 각성**: 한 스킬이 Lv3이 되면 그 스킬이 각성해 더 강해지고 금빛 이펙트가 붙습니다.
- **스킬 공명**: 액티브 스킬 3종이 Lv3 이상이 되면 모든 스킬이 각성(충격파, 금빛 이펙트, 추가 강화), 4종이면 대공명으로 한 단계 더 강해집니다.
- **레벨업 카드**: 경험치 보석을 모아 레벨업하면 카드 3장 중 하나를 고릅니다.
- **적 5종 + 보스**: 추적, 원거리 사격, 돌진. 보스(BOSS 해창)는 추적 → 돌진 → 탄막 → 소환을 반복하는 상태머신이며 체력 절반에서 2페이즈로 바뀝니다.
- **AI 디렉터**: 플레이어의 체력과 처치 속도를 보고 적의 등장량을 실시간으로 조절합니다.
- **난이도 상승**: 시간이 지날수록 적이 더 자주 나오고 더 단단해지며, 1분마다 적이 한 단계씩 빨라지고 배경음악 박자도 빨라집니다.
- **아이템**: 50초마다 포션(체력 회복), 90초마다 자석(경험치 구슬 전부 흡수).
- **타격감**: 하얀 깜빡임, 데미지 숫자, 처치 파편, 화면 흔들림, 효과음.
- **배경음악**: 코드로 합성한 BGM. 시작 화면, 전투, 보스 경고, 보스전에 따라 분위기가 바뀝니다.
- **보스 경고**: 등장 30초 전부터 붉은 화면 맥동, 카운트다운, 사이렌.
- **최고 기록 저장**: `localStorage`.

## 구조

```
index.html       캔버스 + HUD·메뉴·레벨업 카드(HTML 요소)
style.css        레이아웃, 카드·버튼 디자인, 애니메이션
js/config.js     밸런스 수치 모음
js/entities.js   Player, Enemy, Projectile, Gem
js/ai.js         군집 이동, 적 행동, 보스 FSM, AI 디렉터, 스폰
js/weapons.js    무기 3종과 진화
js/upgrades.js   레벨업 카드
js/items.js      포션·자석 아이템
js/awaken.js     스킬 공명(각성)
js/effects.js    데미지 숫자, 파티클, 화면 흔들림
js/music.js      Web Audio 배경음악
js/sfx.js        Web Audio 효과음
js/ui.js         HUD, 메뉴, 결과 화면, 최고 기록
js/main.js       게임 루프, 상태 관리, 입력
```

`type="module"`을 쓰지 않고 일반 `<script>`를 순서대로 불러서, `index.html`을 더블클릭해도 바로 실행됩니다.
