# 심연의 생존자

HTML · CSS · JavaScript만으로 만든 다크 판타지 **뱀서라이크 픽셀 게임**입니다. 10분 동안 살아남거나, 9분에 나타나는 최종 보스를 쓰러뜨리면 승리합니다.

**▶ 바로 플레이: https://castlegyun.github.io/aiffel-agent-3/03-my-game/**

이미지·오디오 파일이 하나도 없습니다. 캐릭터·적·보스·아이콘은 코드 속 글자 도안을 굽고, 효과음과 배경음악은 Web Audio로 직접 합성합니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space (또는 Shift) | 점멸: 짧은 순간이동 + 잠깐 무적 |
| (자동) | 가장 가까운 적을 조준해 공격 |
| ESC | 일시정지 (지금 빌드, 진화 조합표, 설정) |
| M | 소리 켜기/끄기 |
| 터치 | 화면을 누르고 드래그하면 조이스틱, 오른쪽 아래 점멸 버튼, 오른쪽 위 ❚❚ 일시정지 |

## 주요 기능

- **픽셀 화면**: 세계를 640x360 정도의 작은 그림판에 그린 뒤 정수 배로 확대합니다. 캐릭터뿐 아니라 탄·폭발·번개·데미지 숫자까지 같은 크기의 도트입니다.
- **조명**: 화면을 어둠으로 덮고 플레이어의 횃불, 탄, 폭발, 화로·용암·수정 주변만 계단식으로 밝힙니다.
- **10분 3막**: 1막 버려진 던전 → 2막 용암 지대 → 3막 심연. 막마다 바닥 색·장식·음악 층이 바뀝니다. 분 단위 웨이브 표와 사건(포위, 박쥐 떼, 벽, 정예 등장)이 흐름을 만듭니다.
- **보스 3종**: 3:00 해골 기사단장(돌진, 틈이 있는 충격파), 6:00 심연의 리치(순간이동, 나선 탄막, 저주 지대), 9:00 BOSS 해창(3페이즈, 휩쓰는 광선 포함). 위험한 공격은 모두 바닥 예고가 먼저 뜹니다.
- **적 12종**: 해골, 임프, 중갑병, 광신도, 지옥 사냥개, 박쥐, 자폭병, 슬라임(분열), 유령(통과), 강령술사(소환), 감시자의 눈(포탑). 금빛 테두리의 정예는 상자를 떨어뜨립니다.
- **무기 8종 + 패시브 10종**: 무기 6칸 + 패시브 6칸. 무기가 최대 레벨이고 짝이 되는 패시브를 가지고 있으면 진화합니다(조합표는 일시정지 화면).
- **스킬 Lv3 각성과 스킬 공명**: 스킬이 Lv3이 되면 각성하고, 3종이 각성하면 공명, 5종이면 대공명이 터집니다.
- **타격감**: 넉백, 치명타(큰 노란 숫자), 연달아 맞으면 합쳐지는 데미지 숫자, 히트스톱, 하얗게 흩어지는 죽음, 땅에서 솟아오르는 등장, 보석 등급(초록·파랑·빨강·금빛).
- **아이템**: 포션, 자석, 폭탄, 상자(정예·보스).
- **설정**: 효과음·배경음악 음량, 화면 흔들림, 데미지 숫자 끄기. 브라우저에 저장됩니다.
- **AI 디렉터**: 플레이어의 체력과 처치 속도를 보고 적의 등장량을 0.7~1.3배로 조절합니다.

## 구조

```
index.html       캔버스 + HUD·메뉴·레벨업·상자·일시정지·결과 화면(HTML)
style.css        픽셀 UI (모든 선 굵기를 도트 한 칸 --px의 배수로)
js/config.js     밸런스 수치 모음 (무기·패시브·적·보스·웨이브·사건)
js/render.js     픽셀 그림판, 확대, 조명, 도트 원·선 도우미
js/sprites.js    글자 도안 → 아틀라스, 자동 외곽선·반전·피격·죽음 프레임, 아이콘, 숫자 글꼴
js/passives.js   패시브와 무기에 곱해지는 배율(Build)
js/entities.js   Player, Enemy, 탄, 보석
js/ai.js         격자 탐색, 군집 이동, 적 행동 9종, AI 디렉터
js/bosses.js     보스 상태머신, 위험 지대(충격파·예고 폭발·광선)
js/waves.js      분 단위 웨이브와 사건, 적 생성
js/weapons.js    무기 8종과 강화·각성·진화
js/upgrades.js   레벨업 카드와 상자 보상
js/items.js      포션·자석·폭탄·상자
js/awaken.js     스킬 공명(각성)
js/effects.js    파티클, 숫자, 섬광, 죽음 연출, 히트스톱, hitEnemy
js/background.js 막별 바닥 타일과 장식
js/music.js      Web Audio 배경음악 (막마다 층이 더해진다)
js/sfx.js        Web Audio 효과음, 설정
js/ui.js         HUD, 화면들, 최고 기록
js/main.js       게임 루프, 상태 관리, 입력
js/gallery.js    검수용 화면 (주소 끝에 ?gallery)
```

`type="module"`을 쓰지 않고 일반 `<script>`를 순서대로 불러서, `index.html`을 더블클릭해도 바로 실행됩니다.
