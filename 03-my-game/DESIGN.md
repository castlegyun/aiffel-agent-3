

## 🎮 뱀서류 게임 설계서

**목표**: 4분 동안 살아남거나, 그 전에 보스(BOSS 해창)를 쓰러뜨리면 승리
**스타일**: ~~네온 도형 스타일~~ → **다크 판타지 던전** (아래 "비주얼 스타일 가이드" 참고)
→ 이미지 에셋 없이 canvas 코드로 직접 그립니다. 저작권 걱정이 없습니다.
(엔티티·HUD는 단계별로 새 스타일로 바꿔 갑니다. 현재 적용 완료: 배경 타일 + 비네팅)

### 필수 기능

1. **이동**: WASD·방향키. 대각선으로 움직여도 속도가 같게 맞춥니다. 카메라가 플레이어를 따라가고, 배경에는 격자가 무한히 이어집니다.
2. **적 5종**: 화면 밖에서 생겨나 플레이어를 쫓아옵니다. 적끼리는 서로 밀어내서(군집 이동) 한 점에 겹치지 않습니다.
   - 기본형 / 빠르지만 약한 형 / 느리지만 단단한 형
   - 원거리형: 일정 거리를 유지하며(가까우면 물러나고 멀면 다가옴) 주기적으로 탄을 쏩니다.
   - 돌진형: 다가오다 멈추고 → 예고선 표시(0.6초) → 직선으로 돌진 → 쿨다운
3. **무기 4종**
   - 기본 탄: 가장 가까운 적에게 자동 발사
   - 회전 구슬: 플레이어 주위를 돌며 공격
   - (스킬 강화) 불꽃탄은 레벨업마다 발사 수가 1발씩 늘고(Lv5에 5발) 맞은 자리에서 폭발하며 불꽃 꼬리가 남습니다. 회전 구슬은 푸른 꼬리와 타격 불꽃, 레이저는 지직거리는 번개 줄기와 충격 고리, Lv3에 광선 +1(진화하면 4줄기)입니다.
   - **스킬 Lv3 각성** (✅ 구현 완료): 한 스킬이 Lv3이 되면 그 스킬만 각성해 더 강해지고(불꽃탄: 폭발 범위 x1.4·폭발 피해 80%·탄 커짐, 구슬: 커지고 궤도 확대·타격 간격 단축, 번개: +2마리·확산 x1.25·피해 감소 완화, 레이저: 능력치 변화 없이 금빛 이펙트만), 작은 충격파·금빛 파편·안내 문구가 터집니다. 카드에 미리 "✦ 각성" 내용이 표시됩니다.
   - **카드 등장 확률**: 레이저는 너무 강해서 다른 스킬의 약 35% 확률로만 카드에 나옵니다(`config.js`의 `cardWeights`).
   - **스킬 공명(각성)** (✅ 구현 완료, `js/awaken.js`): 액티브 스킬 3종이 각각 Lv3 이상이 되면 1단계 "공명", 4종이 모두 Lv3 이상이면 2단계 "대공명"이 발동합니다. 발동 순간 금빛 섬광과 충격파가 터져 주변 적에게 피해를 주고 밀어내며, 모든 스킬의 피해와 속도가 오르고 스킬마다 추가 강화(불꽃탄 폭발 확대, 구슬 +1·커짐, 레이저 굵고 길게, 번개 +1마리·확산 확대)와 금빛 이펙트가 붙습니다. 이후 발밑에 금빛 오라가 남고, 이미 발동한 뒤 새로 얻은 무기도 같은 강화를 받습니다.
   - 연쇄 번개: 가장 가까운 적을 내려치면 맞은 적에서 주변 적으로 번개가 튀며 이어짐 (확산 거리 130px, 기본 4마리, 맞을 때마다 피해 12% 감소). Lv2·Lv4에 대상 +1, 레벨마다 확산 거리 증가, 진화하면 번개 2줄기 동시 + 최대 9마리 (천둥 폭풍)
   - 레이저: 가까운 적 방향으로 긴 광선을 쏴서 직선 위의 모든 적을 관통 (원래 계획의 "오라"는 회전 구슬과 비슷해서 교체)
4. **충돌·체력**: 원끼리 거리로 판정합니다. 맞은 직후 잠깐 무적이 되고, 체력이 0이면 게임오버입니다.
5. **성장**: 적이 경험치 보석을 떨어뜨리고, 가까이 가면 보석이 끌려옵니다. 레벨업하면 게임이 멈추고 카드 3장 중 하나를 고릅니다.
   - 선택지: 새 무기, 무기 강화, 이동속도, 최대체력, 자석 범위
   - 카드에 현재 레벨 → 다음 레벨과 바뀌는 수치를 표시합니다. (예: 데미지 10 → 14)
   - **무기 진화**: 무기가 최대 레벨(5)이 되면 다음 레벨업 때 진화 카드가 나옵니다.
     - 기본 탄 → 관통 화염탄 (모든 적을 뚫고 지나가는 탄)
     - 회전 구슬 → 구슬 개수 2배, 궤도 확장
     - 레이저 → 폭풍 레이저: 광선 4줄기를 부채꼴로 동시 발사
6. **난이도 상승**: 시간이 지날수록 적이 더 자주 나오고 체력도 늘어납니다. 3분 20초쯤 보스가 등장합니다.
   - **1분마다 한 단계 빨라짐** (✅ 구현 완료): 1분이 지날 때마다 적 이동 속도가 한 단계씩(+25%: x1.25 → x1.50 → x1.75, 상한 x2.0) 오르고 배경음악 박자도 12%씩 빨라지며, 화면 가장자리가 붉게 번쩍이고, "⏱ N분 경과! 적이 더 빨라진다" 문구와 소리로 알립니다.
   - (이전 설계) **적 이동 속도 증가**: 시간이 지날수록 적의 이동 속도도 빨라집니다. 게임 전체 속도가 아니라 적의 속도만 올려서, 플레이어 조작감은 그대로입니다. 너무 빠르면 피할 수 없으니 상한을 둡니다(기본 속도의 1.4배). 이미 나와 있는 적에게도 적용됩니다. (✅ 구현 완료)
   - **AI 디렉터**: 플레이어의 체력 비율과 최근 처치 속도로 "긴장도"를 계산해, 기본 난이도 곡선 위에서 스폰량을 0.7~1.3배로 조절합니다. 잘하면 더 몰아치고, 위기면 숨 돌릴 틈을 줍니다.
   - **보스 등장 경고** (✅ 구현 완료): 등장 30초 전(2분 50초)부터 화면 가장자리가 붉게 맥동하고(등장이 가까울수록 더 빠르고 진하게), "보스 출현까지" 카운트다운과 안내 문구가 뜨고, 사이렌이 울리며(마지막 10초는 두 배로 잦게) 음악이 긴장감 있게 바뀝니다.
   - **보스 상태머신(FSM)**: 추적 → 돌진 → 원형 탄막 → 졸개 소환을 순환합니다. 체력이 50% 이하가 되면 2페이즈로 넘어갑니다(속도·탄 수 증가, 색 변화).
7. **바닥 아이템** (✅ 구현 완료, `js/items.js`): 플레이어 주변 220~480px의 무작위 위치에 생깁니다. 안 주우면 다음 주기에 새 위치로 옮겨져 항상 하나만 존재하고, 화면 밖이면 가장자리에 방향 화살표가 뜹니다.
   - **포션**: 50초마다 생성. 체력 2.5칸(체력 칸 하나 = 20이므로 50)을 회복합니다.
   - **자석**: 1분 30초마다 생성. 맵의 모든 경험치 구슬이 플레이어에게 빠르게 날아와 흡수됩니다.
8. **화면 구성**
   - HUD: 체력바, 경험치바, 레벨, 시간, 처치 수
   - **남은 시간**: 화면 상단 중앙에 크게 `mm:ss`로 카운트다운합니다(4:00 → 0:00). 멀리서도 읽히는 큰 숫자이고, 마지막 30초는 붉게 깜빡여 긴장감을 줍니다. 보스 등장(3:20) 때는 타이머가 붉게 물들며 크게 커졌다가 조금 큰 채로 자리 잡고, 화면 가장자리에 붉은 섬광이 지나갑니다. (✅ 구현 완료, 8단계에서 프레임 디자인만 다듬음)
   - 시작 / 일시정지(ESC) / 게임오버 / 승리 화면, 재시작 버튼
   - 결과 화면 통계: 생존 시간, 적 종류별 처치 수, 최고 레벨, 최고 기록 갱신 여부
9. **최고 기록 저장**: `localStorage` 사용

### 퀄리티 올리는 추가 기능 (필수가 끝나면)

- **타격감**: 적이 맞으면 하얗게 깜빡이고, 데미지 숫자가 뜨고, 처치 시 파티클이 튑니다. 피격 시 화면이 흔들립니다.
- **효과음**: Web Audio로 코드에서 직접 생성합니다. 파일이 필요 없습니다. (돌진 몬스터와 보스는 돌진 시작 때 거리에 따라 크기가 달라지는 돌진 소리가 납니다.)
- **모바일 대응** (✅ 구현 완료): 화면을 누르면 그 자리에 가상 조이스틱이 생기고 끌어서 이동합니다. 터치 기기에서는 일시정지(❚❚) 버튼과 터치용 조작 안내가 보이고, 작은 화면에서는 HUD와 카드 크기가 줄어듭니다.

> 체감 퀄리티의 절반은 타격감에서 나옵니다. 시간이 부족해도 이건 꼭 넣으세요.

### 코드 구조

```
index.html   캔버스 + HUD·메뉴·레벨업 카드(HTML 요소)
style.css    레이아웃, 카드·버튼 디자인, 애니메이션
js/config.js    밸런스 수치 모음 (속도, 체력, 스폰 간격 등)
js/entities.js  Player, Enemy, Projectile, Gem 클래스
js/ai.js        군집 이동, 적 타입별 행동, 보스 FSM, AI 디렉터
js/weapons.js   무기 3종 + 진화
js/upgrades.js  레벨업 카드 강화 목록(무기 강화, 이동속도, 최대체력, 자석 범위)
js/effects.js   데미지 숫자, 파티클, 화면 흔들림, hitEnemy(모든 공격이 지나가는 함수)
js/sfx.js       Web Audio 효과음 합성 (파일 없음), 음소거
js/music.js     Web Audio 배경음악 합성 (시작 화면/전투/보스 경고/보스전 4가지 분위기)
js/items.js     바닥 아이템(포션, 자석)과 화면 밖 방향 표시
js/ui.js        HUD, 메뉴, 레벨업 카드
js/main.js      게임 루프, 상태 관리
```

- **HTML/CSS도 보여주기**: 메뉴와 카드를 canvas 대신 HTML/CSS로 만들면, 과제에서 세 가지를 모두 쓴 게 드러납니다.
- **게임 루프**: `requestAnimationFrame`에 deltaTime을 곱해서, 모니터 주사율과 관계없이 같은 속도로 움직이게 합니다. deltaTime은 최대 0.05초로 제한해서 탭을 바꿨다 돌아왔을 때 적이 순간이동하지 않게 합니다.
- **상태 관리**: `menu` / `playing` / `levelup` / `paused` / `gameover` / `victory`
- **스크립트 로드 방식**: `type="module"`을 쓰지 않고 일반 `<script>` 태그를 순서대로 넣습니다(config → entities → ai → weapons → ui → main). 그래야 HTML 파일을 더블클릭해서 바로 열어도 작동합니다.

### 🎨 비주얼 스타일 가이드 (다크 판타지, 레퍼런스 스크린샷 2장 분석)

**전체 인상**: 거의 검은 갈색의 어두운 던전 바닥 위에, 불·용암·마법이 만드는 따뜻한 빛 덩어리만 밝게 떠 있습니다. 화면 대부분은 어둡고, 밝은 곳은 전부 "공격 이펙트와 광원"이라서 시선이 전투로 모입니다.

**색상 팔레트**

| 용도 | 색 | 코드(근사값) |
|---|---|---|
| 바닥 가장 어두운 곳 / 줄눈 | 검은 갈색 | `#0d0807` |
| 바닥 기본 돌판 | 탁한 적갈색 | `#1c1411` ~ `#2a1d17` |
| 바닥 밝은 돌판 / 모서리 하이라이트 | 따뜻한 갈색 | `#3a2a20` |
| 비네팅(가장자리) | 거의 검정 | `rgba(0,0,0,0.85)` |
| 불·횃불·용암 | 주황 → 노랑 | `#ff7a1a` → `#ffb43a` → `#ffe27a` |
| 지옥불·보스 체력바 | 짙은 붉은색 | `#c4221a` |
| 체력 구슬 | 선홍색 | `#b01818` |
| 마나 구슬 / 마법 | 짙은 파랑 | `#2a4fd0` |
| 경험치 바·경험치 보석 | 초록 | `#3fae4a` / `#2fd07a` |
| 데미지 숫자·골드 | 연한 노랑 | `#e8dca0` |
| UI 프레임 | 어두운 철·뼈 회색 | `#4a3f38` ~ `#8a7a68` |

- 채도 높은 색은 **불(주황), 피(빨강), 마나(파랑), 경험치(초록)** 네 가지 의미로만 씁니다. 나머지는 모두 저채도 갈색·회색입니다.
- 이전 설계의 시안 네온(`#00f0ff`)은 쓰지 않습니다.

**조명**
- 광원은 횃불, 촛불, 용암 웅덩이, 불 마법입니다. 모두 **따뜻한 점광원**이고, 둘레로 갈수록 어두워지는 원형 번짐으로 그립니다.
- 이펙트(불꽃·번개·레이저)는 `globalCompositeOperation = 'lighter'`(가산 합성)로 겹쳐 그려 빛나는 느낌을 냅니다.
- 파란 마법만 차가운 보조광으로 대비를 줍니다.
- 화면 가장자리는 강한 **비네팅**으로 어둡게 눌러, 플레이어 주변이 가장 밝아 보이게 합니다.
- 피격 시 붉은 비네팅이 잠깐 강해지는 연출을 나중에 추가할 수 있습니다.

**바닥(배경)**
- 어두운 돌판이 깔린 던전 바닥입니다. 돌판마다 명도가 조금씩 다르고, 줄눈은 더 어둡고, 모서리에 얇은 하이라이트가 들어갑니다.
- 군데군데 금, 균열, 얼룩이 있어서 반복 무늬 티가 나지 않게 합니다.
- 장식(기둥, 촛불, 용암 웅덩이, 핏자국)은 나중 단계에서 배경 위에 추가합니다.

**UI 구성**
- **하단 중앙**: 레벨 숫자. 그 아래로 화면 전체 너비의 **분할형 초록 경험치 바**.
- **체력**: 하단 구슬 없이 캐릭터 머리 위 칸 나누기 체력바(칸 하나 = 체력 20)만 씁니다.
- **구슬 옆 소형 슬롯**: 물약 개수, 골드. 어두운 철 프레임에 연한 노랑 숫자.
- **상단 중앙**: 작은 프레임 안의 생존 타이머(`mm:ss`).
- **보스전**: 상단 중앙에 장식 프레임을 두른 **붉은 보스 체력바**와 보스 이름.
- **전투 텍스트**: 적 머리 위로 떠오르는 연한 노랑 데미지 숫자(크리티컬은 크고 밝게).
- HUD 프레임은 HTML/CSS로 만들고(그라디언트·테두리·그림자), 체력 구슬은 CSS로 그립니다.

**캐릭터 스타일 (Tower of Babel 풍)**
- 작은 **도트(픽셀) 캐릭터**에 굵은 어두운 외곽선, 단순한 2~3톤 음영. 레퍼런스의 뾰족 모자 + 하얀 수염 마법사를 기본 플레이어로 합니다.
- 문자열 도안을 `js/sprites.js`에서 offscreen canvas로 구워 두고, `imageSmoothingEnabled = false`로 정수배 확대해서 도트가 번지지 않게 합니다.
- 이동 방향에 따라 좌우 반전, 걷기는 2프레임 + 살짝 들썩이는 효과, 발밑에 타원 그림자를 깝니다.
- 적도 같은 방식(어두운 외곽선 + 도트)으로 만들어 통일감을 유지합니다.

**카메라 / 연출**
- 레퍼런스는 비스듬한 시점이지만, 판정과 구현이 단순하도록 **탑다운 시점**으로 유지합니다.
- 적이 많이 몰려도 형태가 읽히도록 적은 어두운 실루엣 + 밝은 눈/무기 포인트로 그립니다.

**적용 순서 (비주얼 개편)**
1. ✅ 던전 바닥 타일 + 가장자리 비네팅
2. 플레이어(✅ 도트 마법사)·적 스프라이트를 다크 판타지 스타일로 교체
3. 광원(플레이어 주변 빛, 불 이펙트 가산 합성)
4. ✅ HUD(머리 위 체력바, 경험치 바, 무기 슬롯, 타이머, 보스 바)
5. 데미지 숫자, 파티클, 장식 오브젝트
